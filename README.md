## 🔥 Project Overview

**This tool** is a comprehensive trainer for **Rogue Blight**. This trainer provides optional assistance for single-player runs by managing health, mana, stamina, currency, character progression, and equipment-related resources. It is designed to reduce repetitive grinding while preserving the game's exploration, combat, map choices, and roguelite structure.

**Target Audience:** Players who want to explore Rogue Blight's procedural maps, weapons, blessings, challenge maps, and New Game Plus progression with reduced grinding or a more accessible difficulty level.

> **⚠️ IMPORTANT:** This tool is for **educational and private use only**. It does not modify any game files — all changes are temporary and reset when the game closes. The tool is **undetectable**, but **use it at your own risk**. Always back up your save files before use.

## 📖 Detailed Feature Guide

### Movement & Exploration

Rogue Blight is a 2D action game built around deliberate movement and Souls-like combat timing. Use the trainer's defensive options when learning enemy patterns, navigating unfamiliar routes, or practicing movement through difficult encounters.

### Tools & Inventory

The game supports one-handed weapons, shields, blessings, and equipment upgrades. Use inventory-related options carefully and avoid changing values while moving items, purchasing equipment, or smelting gear at the blacksmith.

### World & Environment

Each run travels through three randomly generated maps containing different enemies, backgrounds, encounters, chests, shops, statues, and blacksmiths. Permanent progression carries benefits into future runs, while Story Mode also includes increasingly difficult New Game Plus cycles.

### Combat & Weapons

Combat features weapons such as swords, daggers, wands, and shields, with more than 50 weapons offering unique skills. Status effects include Bleed, Poison, Burn, Freeze, Shock, Choke, Shatter, Life Splash, Darkness, and Light Struck. Enable combat options before entering an encounter and disable them when testing normal damage or achievement progress.
